# Prova de Administradores — Dom Bosco

Página informativa estática para o processo de seleção.

## Publicar gratuitamente com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve. O GitHub mostrará a URL pública quando a publicação terminar.

## Limitação importante
Esta versão é somente informativa. GitHub Pages hospeda arquivos estáticos; não fornece banco de dados, autenticação segura, recebimento sigiloso de respostas nem fechamento confiável da prova. Não use esta página para coletar respostas. Para a prova funcional, conectar um backend (por exemplo, Supabase) com políticas de acesso no servidor e painel administrativo protegido.
